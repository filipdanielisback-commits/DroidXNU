# Driver research

This directory is reserved for original DroidXNU driver work.

No Moto G60 drivers have been implemented or validated. The current [driver research matrix](driver-matrix.md) lists the subsystems that need hardware identification, public source references, interface analysis, license review and test evidence.

A Linux driver is useful as a hardware reference but is not automatically reusable as an XNU driver. Do not add proprietary firmware blobs or claim a device feature works without a reproducible test. See [device compatibility](../docs/compatibility.md).
