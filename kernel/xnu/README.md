# XNU integration research

No XNU source has been copied into this directory yet.

The first task is to study the exact upstream revision and its build requirements, then document which parts are portable and which depend on Apple platform support. XNU is a kernel component of Darwin, not a complete iOS system.

Upstream: https://github.com/apple-oss-distributions/xnu

Before importing or modifying source, record the exact commit, preserve notices, and follow the applicable APSL terms. See [licensing policy](../../docs/licensing.md).

No kernel patch or bootable kernel is currently available.
